# Prime Survival
## Development Roadmap

This roadmap outlines the planned development stages for Prime Survival.

---

# Phase 1 — Foundation

Goal:
Create a playable world where the player can move and explore.

Features:
- Project setup
- Player movement
- First-person camera
- Terrain
- Sky and lighting
- Water
- Trees and vegetation
- Ambient audio
- Day/Night cycle
- Weather framework
- Performance optimization

---

# Phase 2 — Core Survival

Goal:
Allow the player to survive in the world.

Features:
- Health
- Hunger
- Thirst
- Stamina
- Inventory
- Item pickup
- Resource gathering
- Basic save system

---

# Phase 3 — Crafting & Building

Goal:
Enable players to create tools and build shelters.

Features:
- Crafting system
- Placeable structures
- Building pieces
- Storage containers
- Workbench

---

# Phase 4 — Wildlife

Goal:
Populate the world with living creatures.

Features:
- Passive animals
- Predators
- Animal AI
- Hunting
- Loot collection

---

# Phase 5 — World Expansion

Goal:
Make exploration more rewarding.

Features:
- Points of interest
- Caves
- Rivers
- Waterfalls
- Abandoned buildings
- Hidden locations

---

# Phase 6 — Polish

Goal:
Prepare the game for public testing.

Features:
- UI improvements
- Audio improvements
- Graphics optimization
- Bug fixing
- Game balancing

---

# Future Phases

- Vehicles
- NPCs
- Story mode
- Multiplayer
- Steam release
