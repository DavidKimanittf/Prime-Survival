# Prime Survival
## Asset Pipeline

## Purpose

This document defines how all assets are sourced, created, organized, and imported into the project.

The goal is to maintain a consistent, high-quality asset library throughout development.

---

# Asset Sources

Only use assets that are:

- Original creations
- Public domain
- CC0 licensed
- MIT licensed
- Properly licensed for commercial use

Every asset source must be documented.

---

# Preferred Sources

- Kenney
- Poly Haven
- AmbientCG
- OpenGameArt (license must be verified)
- Sketchfab (only models with compatible commercial licenses)

---

# 3D Models

Preferred format:
- .glb

Requirements:
- Clean topology
- Correct scale
- Realistic proportions
- PBR-compatible materials

---

# Textures

Formats:
- .png
- .webp

Recommended sizes:
- 512×512
- 1024×1024
- 2048×2048

---

# Audio

Formats:
- .ogg (music and ambience)
- .wav (short sound effects)

---

# Naming Examples

Tree_Oak_01.glb
Rock_Granite_03.glb
River_Ambience.ogg
Footstep_Grass.wav

Use descriptive names.
Avoid spaces.
Use version numbers only when necessary.

---

# Import Rules

- Test every asset before committing.
- Remove unused assets.
- Optimize large textures.
- Keep the repository organized.
