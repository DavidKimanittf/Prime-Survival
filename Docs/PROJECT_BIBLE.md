# Prime Survival
## Project Bible

### Mission

Build a commercial-quality open-world survival game using only free and open-source development tools wherever practical.

---

## Core Values

- Player freedom over scripted gameplay.
- Exploration should always feel rewarding.
- Every system should be modular.
- Performance is a feature.
- Code should remain clean and maintainable.
- Future multiplayer support must always be considered.

---

## Development Principles

1. Never rush implementation.
2. Complete one system before starting another.
3. Test every feature before moving on.
4. Avoid duplicate code.
5. Keep systems independent.
6. Optimize continuously rather than at the end.
7. Document major decisions.

---

## Definition of Done

A feature is complete only when:

- It works reliably.
- It has been tested.
- It is documented.
- It does not break existing systems.
- It follows the project's coding standards.

---

## Long-Term Vision

Prime Survival should become a living, evolving world that players can explore for hundreds of hours while enjoying realistic survival mechanics, emergent gameplay, and a strong technical foundation.
