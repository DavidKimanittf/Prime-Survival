# Prime Survival
## Game Design Document (GDD)

## Project Information

**Project Name:** Prime Survival

**Genre:** Open World 3D Survival

**Perspective:** First Person

**Engine:** Godot 4

**Programming Language:** GDScript

**Version Control:** Git + GitHub

## Vision

Prime Survival is a first-person open-world survival game where the player begins with nothing and must survive by exploring, gathering resources, crafting equipment, building shelters, and adapting to a living world.

The game emphasizes player freedom, exploration, immersion, and long-term progression in a realistic natural environment.

## Development Goals

- Create a beautiful open world.
- Build systems using modular architecture.
- Design for future multiplayer support.
- Keep performance optimized.
- Release first on Windows, Linux, and Android, with future support for Steam.
