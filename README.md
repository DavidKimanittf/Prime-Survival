# Prime Survival

## Overview

Prime Survival is an open-world first-person survival game being developed with Godot 4 using GDScript.

The project follows a modular architecture inspired by professional game development practices, with a strong focus on scalability, optimization, maintainability, and future multiplayer support.

---

## Current Development Phase

Phase 1 — Foundation

Current objectives:

- Project planning
- Technical architecture
- World design
- Repository organization
- Documentation

---

## Planned Features

- Large open world
- First-person gameplay
- Dynamic day and night cycle
- Dynamic weather
- Wildlife AI
- Crafting system
- Building system
- Inventory system
- Resource gathering
- Vehicles (future)
- Multiplayer-ready architecture
